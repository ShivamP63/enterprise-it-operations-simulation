# Postman API Support Tests

This folder contains a safe, importable Postman simulation for incident `INC0010002`. It uses `https://postman-echo.com` and does not require credentials.

## Files

- `Inventory-API-Support-Tests.postman_collection.json` — three requests with automated assertions.
- `Local-Simulation.postman_environment.json` — local variables for the public echo endpoint and incident number.

## Run the collection

1. Open Postman and select **Import**.
2. Import both JSON files.
3. Select the **Local Simulation** environment.
4. Open **Inventory API Support Tests**.
5. Run each request individually or use the Collection Runner.

## Expected results

| Request | Expected status | Assertions |
|---|---:|---|
| `01 - Health check` | 200 | Status is 200; response time is below two seconds |
| `02 - Reproduce unauthorized request` | 401 | Status is 401; no Authorization header is present |
| `03 - Verify access after remediation` | 200 | Status is 200; response contains `result=authorized` |

## Safety

The 401 response is generated by a deterministic public status endpoint. The collection intentionally sends no bearer token, password, cookie, or production identifier.
