## Customer-visible description

Users report receiving HTTP 401 Unauthorized when accessing the Inventory Management application immediately after resetting their corporate password. Identity-provider authentication completes successfully, but the application rejects authenticated requests. Multiple users are affected, suggesting an application authentication or session-token validation issue rather than an isolated account problem.

**Business impact:** Employees cannot update inventory or process related orders.

## Resolution note

Application-side cached session state was invalidated and the user obtained a fresh access token. Authenticated API requests returned HTTP 200, the inventory dashboard loaded, and an inventory update completed successfully.
